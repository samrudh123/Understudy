# Low-level design

Machine-readable API specifications, generated by `python scripts/export_openapi.py`:
[edge](openapi/edge.json) · [gateway](openapi/gateway.json) ·
[teacher](openapi/teacher.json) · [console](openapi/console.json).
Rationale is in [`decision_log.md`](decision_log.md); the big picture is in [`HLD.md`](HLD.md).

## 1. Package layout (`src/understudy/`)

### `common/`: shared by every block

| Module | Key objects | Responsibility |
|---|---|---|
| `config.py` | `repo_root()`, `resolve()`, `load_params()`, `load_services(path, environ)` | Root is `$UNDERSTUDY_ROOT`, or the nearest parent with `params.yaml` + `configs/`. Applies the `UNDERSTUDY_<SECTION>_<KEY>` overrides (values parsed as YAML). |
| `schemas.py` | `Route`, `QueryLogRecord`, `FeedbackRecord`, `Candidate`, `Draft`, `ApprovalRecord` | Pydantic data contracts (§4). |
| `pii.py` | `scrub(text) -> ScrubResult(text, counts)`, `scrub_text()` | Replaces e-mail, IPv4, roll number (`AA00A000`) and number-like spans (card if 13–19 digits and Luhn-valid, phone 10–13, account ≥ 9) with `<TYPE>` placeholders. |
| `text.py` | `normalize()`, `dedupe_key()`, `NORMALIZER_VERSION` | NFKC, straight quotes, control characters removed, lower-case, whitespace collapsed. `dedupe_key` also drops punctuation. |
| `embeddings.py` | `HashingEncoder`, `SentenceTransformerEncoder`, `get_encoder(name, revision)` | `hash:<dim>` is a deterministic offline encoder for tests. Every encoder returns L2-normalised float32. |
| `sse.py` | `format_event`, `parse_events`, `aparse_events`, `MEDIA_TYPE`, `SSE_HEADERS` | SSE encoding and parsing (§3). |
| `metrics.py` | `StageReport`, `stage_run(stage)` | Times a pipeline stage, writes `reports/stages/<stage>.json`, pushes to the Pushgateway, re-raises failures. |
| `tracking.py` | `tracking_uri()`, `setup_mlflow(experiment, uri)`, `TrackingUnavailableError`, `MODEL_NAME` | Selects the MLflow server after checking `/health`. |
| `lineage.py` | `git_commit()`, `git_is_dirty()`, `file_sha256()` | Lineage for reports and runs. |
| `logs.py` | `JsonFormatter`, `configure_logging()`, `get_logger()` | One-line JSON logs. `extra=` fields become JSON keys. |
| `spark.py` | `get_spark(app, params)` | Local SparkSession (UTC, Arrow on). |
| `plotting.py` | `style_axes`, palette constants | Shared chart style. |

### `data/`

| Module | Key objects | Responsibility |
|---|---|---|
| `clinc.py` | `Clinc`, `load_clinc()` | Reads `data_full.json` + `domains.json`. |
| `ingest.py` | `download()`, `ingest_dataset()`, `ingest_logs()`, `IngestError` | Checksummed download with retries. Concatenates `*.jsonl` logs into `data/snapshots/{querylog,feedback}.jsonl` plus a manifest. |
| `validate.py` | `Checks`, `validate_dataset()`, `run()` | Dataset structure, label and length checks. Log rows are validated against the schemas. Writes `reports/validation.json` and exits 1 on failure. |
| `simulate_traffic.py` | `plan_week()`, `generate_week()`, `simulate_offline()`, `simulate_online()`, `parse_weeks()` | Weekly traffic (Zipf, domain schedule, surge, OOS, PII). Offline writes files with oracle routing. Online replays against `POST /ask`. |
| `eda.py` | `plot_*` | `reports/eda/*.png` and `summary.json`. |

### `pipeline/`: one module per DVC stage

| Module | Entry | Notes |
|---|---|---|
| `preprocess_spark.py` | `run(params, raw_dir, snapshot_dir, out_dir)` | PERMISSIVE JSON read with `_corrupt_record`, pandas UDFs `normalize_udf`/`scrub_udf`, dedupe on `request_id`, `week = coalesce(sim_week, floor(days since start_date / 7))`. |
| `mine_frequent_spark.py` | `run(params, logs_dir, approvals_dir)` | `fallback_window` (the window is anchored on the simulated clock when simulated rows exist), `embed` (`mapInPandas`), `choose_k_and_cluster` (KMeans cosine, count-weighted, k by silhouette over `avg_cluster_size_grid`), `merge_similar_clusters` (union-find, centroid cosine ≥ 0.75), `summarise_clusters` (support, cohesion, `new` / `known_but_missed`), `candidate_id` (sha1 of representative). |
| `distil_ray.py` | `run(params)` | Drafts undecided `new` candidates with a Ray `ActorPool` of `DistilWorker` (each holds an engine). One greedy retry per draft. Cache in `data/teacher_cache/<sha1(model, prompt version, examples)>.json`. `clean_paraphrases` filters duplicates, PII, guard failures and length. |
| `approve.py` | `load_drafts`, `load_approvals`, `pending`, `decide`, `auto_review`, `faq_id_for` | Decisions are written as `data/approvals/faq-<id>.json`. `merge` appends phrasings to an approved FAQ. `auto_review` is the simulation-only reviewer. |
| `export_encoder.py` | `export(params)` | MiniLM to ONNX (opset 17, pooling and normalisation in the graph), `quantize_dynamic(QUInt8, per_channel=True)`, quality and latency report. |
| `build_dataset.py` | `run(params)` | `positives`, `log_negatives`, `traffic_weights`. Writes `data/dataset/*`. |
| `train.py` | `run(params)` | Embeds once, Ray Tune `trainable`/`search_space`, refits the best, `choose_tau`, test metrics, plots, MLflow parent and nested runs, pyfunc log, `models/student`. |
| `evaluate_gate.py` | `run(params)` | `evaluate`, `behavioural`, `champion_predictor`. Writes `reports/gate.json`. |
| `register.py` | `register(params)`, CLI `status`/`rollback`/`promote`, `reload_edge()` | Registry writes and edge reload. |

### `student/`

| Module | Key objects | Responsibility |
|---|---|---|
| `encoder.py` | `OnnxEncoder(model_dir, threads, batch_size)` | `tokenizers` + `onnxruntime`. Truncates to `max_seq_len` and L2-normalises. |
| `head.py` | `Head(kind, labels, weights, config)`, `train_head()`, `FALLBACK` | `predict_proba` in numpy for `logreg`, `mlp` and `centroid`. Saved as `head.npz` + `head.json`. |
| `answer_bank.py` | `FAQ`, `AnswerBank` | `version` = sha256 of the sorted content (first 12 hex characters). |
| `model.py` | `Prediction`, `StudentPredictor`, `save_student()`, `StudentPyfunc` | `predict()` returns the top FAQ, its confidence, whether the head voted fallback, and the top 3. `accepts(p, tau)` = no fallback vote and confidence ≥ τ. |
| `router.py` | `Router`, `RouteDecision`, `RELATED_MIN_CONFIDENCE = 0.25` | `route`, `route_many`. Builds related suggestions for fallbacks. |
| `evaluation.py` | `Outcomes`, `metrics_at()`, `choose_tau()` | Instant precision, coverage, OOS / uncovered / total false-accept, traffic-weighted variants. |
| `registry.py` | `alias_version`, `download_student`, `promote`, `rollback`, `versions`, `CHAMPION`, `CHALLENGER` | MLflow registry helpers. |
| `pyfunc_entry.py` | | MLflow models-from-code entry. |

## 2. REST endpoints

### Edge (`:8001`)

| Method, path | Request | Response | Status codes |
|---|---|---|---|
| `POST /ask` | `{"question": str ≤ 4000, "stream": bool = true, "request_id"?: str ≤ 64, "simulated"?: {"week": int, "label"?: str, "domain"?: str}, "use_teacher": bool = true}` | `stream=true`: SSE (§3). `stream=false`: JSON. Student: `{route:"student", request_id, faq_id, matched_question, confidence, model_version, latency_ms, answer}`. Teacher: `{route:"teacher", request_id, confidence, model_version, filler, related, answer, teacher}`. Failure: `{…, route:"unavailable" or "rejected", error:{event, code, message}}`. Simulated with `use_teacher=false`: `{route:"teacher", request_id, confidence, teacher_skipped:true, model_version}` | 200; 422 `{route:"rejected", code:"invalid_question", message}` for empty or > 500 characters; 403 if simulation is disabled |
| `POST /predict` | `{"question"}` | `{use_student, faq_id, confidence, matched_question, tau, model_version, inference_ms}` | 200; 503 no model |
| `POST /feedback` | `{"request_id", "helpful": bool}` | `{"status": "recorded"}` | 200 |
| `GET /faqs` | | `{bank_version, faqs:[{faq_id, question}]}` | 200 |
| `GET /info` | | `{model_loaded, model_uri, model_version, loaded_at, tau, n_faqs, bank_version, head, build_id, filler_version}` | 200 |
| `GET /health` | | `{"status":"ok"}` | 200 |
| `GET /ready` | | `{"status":"ready","model_version"}` | 200; 503 `{"status":"loading"}` |
| `POST /admin/reload` | header `X-Admin-Token` if configured | `{reloaded:true, before, after, faqs, tau}` | 200; 403 bad token; 500 `{reloaded:false, error, serving}` (old model kept) |
| `GET /metrics` | | Prometheus text | 200 |

`request_id` is honoured only for simulated requests (the simulator passes its seeded ids,
so re-runs de-duplicate in `preprocess`). Live requests get a fresh UUID.

### Teacher (`:8000`, route prefix `/teacher`)

| Method, path | Request | Response | Status codes |
|---|---|---|---|
| `GET /health` | | `{status, model, prompt_version}` | 200 |

| Method, path | Request | Response | Status codes |
|---|---|---|---|

Pipeline targets (`console/runner.py: TARGETS`): `discover` = `dvc repro distil`,
`retrain` = `dvc repro register`, `full` = `dvc repro`. Only one run at a time. History is
kept in `reports/console/pipeline_runs.json`.

## 3. SSE protocol

Every event is `event: <name>\ndata: <json>\n\n` (`common/sse.py`).
Clients use `fetch` streaming because `EventSource` cannot `POST` (`ui/assets/sse.js`).

| Event | Sent by | Payload |
|---|---|---|
| `meta` | edge (first event) | student: `{route:"student", request_id, faq_id, matched_question, confidence, model_version, latency_ms}`. Teacher: `{route:"teacher", request_id, confidence, model_version, filler:{version, title, body}, related:[{faq_id, question, confidence}]}` |
| `meta` | gateway | `{request_id, ttft_ms}` (consumed by the edge, not forwarded) |
| `token` | all | `{t: "text piece"}`. A student answer is one token. |
| `done` | all | student: `{route}`. Teacher: `{tokens, ttft_ms, total_ms, model, prompt_version, gateway_ttft_ms}` |
| `error` | edge / gateway / teacher | edge to client: `{code, message}` with a friendly message. Codes: `prompt_injection`, `empty`, `too_long` (shown as a rephrase prompt); `teacher_unavailable`, `teacher_timeout`, `gateway_unreachable`, `teacher_error`, `generation_failed` (shown as unavailable) |

Both the edge and nginx (`X-Accel-Buffering: no`, `proxy_buffering off`) disable buffering.

## 4. Data schemas (`common/schemas.py`)

**`QueryLogRecord`** (extra fields forbidden, `schema_version` 1): `request_id` (1–64),
`ts` (timezone-aware), `text` (1–2000, scrubbed), `route` (`student`, `teacher`,
`unavailable`, `rejected`), `matched_faq_id?`, `confidence?` ∈ [0, 1], `student_version?`,
`latency_ms?`, `teacher_ttft_ms?`, `source` (`live` or `simulated`), and the
evaluation-only fields `sim_week?`, `sim_label?`, `sim_domain?`.

**`FeedbackRecord`**: `request_id`, `ts`, `helpful`, `source`.

**`Candidate`** (`mine_frequent`): `candidate_id`, `status` (`new` or `known_but_missed`),
`representative_question`, `support`, `n_unique`, `share_of_fallbacks`, `cohesion`,
`examples`, and the evaluation-only `dominant_sim_label?` and `purity?`.

**`Draft`** (`distil`): `candidate_id`, `question`, `answer`, `paraphrases`, `examples`,
`support`, `share_of_fallbacks`, `cohesion`, `teacher_model`, `prompt_version`,
`generated_at`, `latency_s`, `cached`, `dominant_sim_label?`, `purity?`.

**`ApprovalRecord`** (one file per FAQ, extra fields forbidden): `faq_id`, `candidate_id`,
`decision` (`approved` or `rejected`), `question`, `answer`, `paraphrases`, `reviewer`,
`decided_at`, `teacher_model`, `prompt_version`, `log_examples`, `merged_candidates`,
`support?`, and the evaluation-only `source_intent?`.
